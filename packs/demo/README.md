# Demo Pack

A small, setting-neutral content pack for The System. It is a generic dungeon game show: 15 achievements, 24 items across all five rarities, four loot-box tiers, about 80 voice lines for the standard GM buttons, and 40 fake audience chat lines. Item `image` fields point at `images/<id>.webp`. Those files are not included yet, so the UI shows its rarity-colored placeholder until art is added. Use this pack to try the engine, or copy it as a starting template for your own pack.
